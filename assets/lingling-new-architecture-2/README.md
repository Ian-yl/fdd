# Lingling Architecture Fixtures

The architecture input files in this directory remain useful source fixtures. `functional-domain/` and `functional-domain-v2/` are historical snapshots created before the current entity, relationship, structured operation, presentation, and approval contracts. They are not compliant output examples and must not be used as approved input to implementation.

Generate and review a new package with the current scripts when validating this architecture. The cross-project current executable example is regenerated by `project-implementation/assets/golden-simulated/generate.mjs` and verified directly by the project test suite.
